# 바탕화면 메모 (Desktop Memo)

윈도우 바탕화면에 붙어 있는 마크다운 메모장입니다.

- **Win+D / Win+M / 바탕화면 보기**를 해도 사라지지 않고 바탕화면에 남아 있습니다.
- 다른 프로그램을 열면 그 창 뒤로 가려집니다(항상 위에 떠 있지 않음).
- 마크다운 문법이 바로 서식으로 보이고, 기호는 커서가 닿은 부분에서만 나타납니다.
- 글자를 블록 지정한 뒤 **우클릭**하면 서식 메뉴가 나옵니다.
- 위쪽 막대로 이동하고, 가장자리·모서리를 끌어서 크기를 자유롭게 바꿀 수 있습니다.

## 요구 사항

- Windows 10 / 11
- Python 3.8 이상(tkinter 포함, python.org 설치본이면 기본 포함)

추가로 설치할 패키지는 없습니다.

## 실행

`desktop_memo.pyw`를 더블클릭하거나:

```bash
pythonw desktop_memo.pyw
```

부팅할 때 자동으로 켜려면 메모의 `⋯` 메뉴에서 **윈도우 시작 시 자동 실행**을 켜세요.
메모 내용은 같은 폴더의 `notes.json`에 자동 저장됩니다.

## 지원하는 마크다운

| 문법 | 결과 |
| --- | --- |
| `# 제목`, `## 제목`, `### 제목` | 제목 |
| `**굵게**`, `*기울임*`, `***둘 다***` | 굵게 / 기울임 |
| `~~취소선~~`, `==형광펜==`, `<u>밑줄</u>` | 취소선 / 형광펜 / 밑줄 |
| `` `코드` ``, ```` ``` ```` 코드 블록 | 코드 |
| `- 항목`, `1. 항목` | 목록 (Enter로 다음 항목 자동 입력) |
| `- [ ] 할 일`, `- [x] 완료` | 체크박스 (클릭해서 체크) |
| `> 인용` | 인용 |
| `[글자](https://...)`, `https://...` | 링크 (Ctrl+클릭으로 열기) |
| `---` | 구분선 |

## 단축키

| 키 | 기능 |
| --- | --- |
| Ctrl+B / I / U | 굵게 / 기울임 / 밑줄 |
| Ctrl+Shift+X / H | 취소선 / 형광펜 |
| Ctrl+E / K | 코드 / 링크 |
| Ctrl+1 / 2 / 3 / 0 | 제목 1·2·3 / 본문 |
| Ctrl+Shift+8 / 7 / 9 | 글머리 기호 / 번호 / 체크박스 |
| Ctrl+휠, Ctrl+= / Ctrl+- | 글자 크기 |
| Ctrl+N | 새 메모 |
| Tab / Shift+Tab | 목록 들여쓰기 / 내어쓰기 |

## 메뉴

위쪽 막대의 `⋯` 또는 우클릭 → **메모**에서 바꿀 수 있습니다.

- 메모 색상 (노랑·주황·분홍·보라·하늘·연두·흰색·다크)
- 투명도, 글자 크기
- 마크다운 기호 숨기기 켜기/끄기
- 윈도우 시작 시 자동 실행
- 메모 삭제, 종료
